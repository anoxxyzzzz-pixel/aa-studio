# AA Mouse Pro

Pemeta mouse + keyboard ke sentuhan layar untuk game Android (OTG/USB dan Bluetooth), diaktifkan lewat **Shizuku** atau **root**. Berjalan sepenuhnya offline.

## Asal kode dan lisensi

AA Mouse Pro adalah **turunan (fork) dari [XtMapper](https://github.com/Xtr126/XtMapper)** oleh Xtr126 dan kontributor
(lihat `ORIGINAL_CONTRIBUTORS.md`), dengan lisensi **GNU GPL v3** (`LICENSE`). Sebagian kode multi-touch berasal dari
[scrcpy](https://github.com/Genymobile/scrcpy) (Apache-2.0). Lihat `CREDITS.md`.

Perubahan dari versi asli: nama, ikon, ID paket (`com.aamouse.pro`), hanya ABI arm64-v8a & armeabi-v7a (APK lebih kecil),
dan build/rilis lewat GitHub Actions. Karena GPL-3.0, karya turunan ini juga GPL-3.0 dan kode sumbernya terbuka di sini.

AA Mouse Pro **bukan** produk GG Mouse Pro dan tidak berafiliasi dengannya.
